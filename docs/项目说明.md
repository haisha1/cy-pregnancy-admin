# 管理端 Java 项目

本项目使用 Java 8、Spring Boot 2.7.18、Maven 3、MySQL 8、Redis、Flyway 和 JWT。Jenkins 控制器使用 Java 21，应用编译使用工具 jdk8，两者独立。

## 当前职责

管理账号登录、改密、角色与权限、账号管理、审计、知识双表达版本编辑、独立审核、发布和下架；管理 Web 通过同源 /admin/api/ 调用本服务。

四个角色：security_admin 管理账号和审计，content_editor 编辑，clinical_reviewer 审核，publisher 发布。作者不得自审，安全管理员不自动拥有全部业务权限。正常创建和改密遵守既有密码策略；临时 admin/admin 不作为默认种子或生产配置。

## 本机快速启动

先准备 MySQL、Redis、独立开发数据库，再执行：

~~~powershell
Set-Location D:/code/cy-pregnancy/cy-pregnancy-admin/server
powershell -ExecutionPolicy Bypass -File scripts/prepare-local.ps1
powershell -ExecutionPolicy Bypass -File scripts/dev.ps1 -Task run -Connection local
~~~

初次空开发库创建 local_admin，随机密码位于 server/.local/bootstrap-password.txt；不重置已有账号。端口为 18732，健康接口为 http://127.0.0.1:18732/actuator/health。

## 工程结构

仓库根 Jenkinsfile；server/ 下是 Maven 工程。Controller 接收参数，Service 负责业务，Mapper 访问数据库；DTO 不返回凭据。src/main/resources/db/migration 保存有效数据库迁移，不删除或改写已执行版本。

## 验证与维护

~~~powershell
powershell -ExecutionPolicy Bypass -File scripts/dev.ps1 -Task test
powershell -ExecutionPolicy Bypass -File scripts/dev.ps1 -Task package
~~~

上述命令在 Maven 工程目录执行；默认单元测试不连接生产库。数据库集成测试需显式配置专用测试库并单独启用，禁止使用生产连接。Node 环境下可在仓库根执行 node scripts/check-docs.mjs 校验文档。

本项目所有维护文档统一放在仓库根 docs，使用中文名称。不要在根目录、server、src、scripts、deploy 下新增说明文档。保留有运行用途的 Dockerfile、Compose、Jenkinsfile、IDE 启动配置和本地脚本；生成报告和真实配置放 Git 忽略目录。Java 8/Boot 2.7 的依赖维护升级单独安排回归。


当前整理验证：默认单元测试 6 项通过，数据库集成测试按条件跳过；local、remote、prod 三种配置均通过 Spring 实际加载检查，检查未建立数据库连接。远程 SSH 隧道与线上数据联调仍需按环境文档手动验收。
